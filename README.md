# Roseline Home Living

Original React + Vite home-living storefront for `Roseline Sfp Holding Limited`.

## Run

```bash
npm.cmd i
npm.cmd run dev
```

Build with `npm.cmd run build`.

## Demo admin

- Username: `admin@roselinehome.com`
- Password: `Roseline@2026`

The admin page is a frontend demo only. Payment is also a checkout demo: PayPal/Visa/card options are shown, but a real provider account and server-side order handling still need to be connected before accepting live payments.

## Catalog and assets

The catalog contains 5 collections with 12 products each and 60 distinct local WebP product images in `public/assets/`. Generated source contact sheets are not part of the website bundle. Fragile categories such as ceramics and mirrors are excluded. Company registration number and phone were not supplied, so they are not invented in the footer.
